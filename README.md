# ZPG PROJECT

This is my project for a subject ZPG (Basics of computer graphics). This project alone should represent a simple OpenGL engine used personally to learn and study OpenGL. GLFW3 and OpenGL external libraries are required! This project looks into ../external_headers folder --> that contains libraries in their respective folders (glad/glad.h,..).

## Required external libraries
```Comment
glad/glad.h
GLFW/glfw3.h
glm/*
stb/stb_library.h
```

## Build and run

```bash
mkdir build && cd build
cmake ..
make
```
This builds the project and creates an linux executable.

`Launch it` with:
```bash
./LearnOpenGL
```
